# 超级泡泡实时岗位状态看板

生产试运行： https://z58479874.github.io/super-bubble-status-board/

## 014.1 员工管理

店长登录 → 人员 → 员工管理。支持在职/历史人员筛选、姓名/编号搜索、新增全职或固定兼职、编辑资料、可安排岗位、离职与恢复、PIN初始化/重置。与今日是否排班和营业阶段无关。

只有店长可操作长期人员档案，最终权限由已部署的受控RPC校验。新增不自动排班、不自动授予岗位、不生成PIN。恢复使用原编号和历史岗位关系，需重新初始化PIN。

正式代码位于 site；GitHub Actions 校验后发布。所有资源使用相对路径。config.js 只包含浏览器公开配置；不提交服务端密钥、真实PIN或会话凭证。

当前读取继续使用014的前台轮询；本版本未改数据库、未加入Realtime。
